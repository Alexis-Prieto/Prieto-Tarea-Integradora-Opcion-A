## 🔹 OPCIÓN A (FASE 2 - CON IA)

### Requerimientos Funcionales
1. **RF-01: Buscar y filtrar médicos** - Consultar el directorio mediante la barra de búsqueda por texto en tiempo real ("Buscar médico por nombre...") y filtros de especialidad para visualizar el perfil del doctor.
2. **RF-02: Agendar citas** - Seleccionar la fecha y hora disponible para registrar activamente la cita médica y desplegar la pantalla de confirmación ("¡Cita agendada!").
3. **RF-03: Navegar por el menú lateral** - Navegar de forma interactiva entre los módulos del sistema (incluyendo la sección "Perfil") mediante el menú lateral (Drawer).
4. **RF-04: Ver citas agendadas** - Visualizar el historial dinámico de citas en "Mis citas", registrando en tiempo real la nueva reserva en el listado de tarjetas.
